# v1: OpenBadge Inspector MVP

- **Status:** in progress
- **Date:** 2026-11-01
- **Issue:** none

## Goal

A Firefox desktop user can click the toolbar button to mark every `<img>`/SVG on the page with a status icon, or
right-click any image and choose *Inspect Open Badge* to see a card. The card shows what the badge is and which
checks passed, or says the image contains no Open Badges data. Offline checks run automatically; online checks run
only on *Verify online* with the setting enabled. The extension passes `web-ext lint` and is ready for an AMO
submission.

## Non-goals

- OB 1.x, JPEG/WebP/GIF, link-only badges, CSS backgrounds, iframes ([ADR-003](../adr/ADR-003-baked-only-detection.md)).
- Recipient email matching ([ADR-005](../adr/ADR-005-offline-first-verification.md)).
- Criteria, evidence or raw-payload views on the card.
- Firefox for Android, other browsers, languages other than English.
- The AMO submission itself (prepared here, submitted only on the maintainer's go).

## Resolved

- OB3 fixtures → our own generated ones. The 1EdTech samples were dropped: the 1EdTech
  `openbadges-specification` repository states no licence. The W3C `vc-di-eddsa` test vectors (W3C licence) are
  used instead as an independent check of the signature code.
- Task 14: online behaviour is covered by unit tests with a fake HTTP layer; E2E only checks that the *Verify online*
  button appears after the setting is turned on, because the test issuers are not reachable over https.
- Task 15: README, PRIVACY, icon, reproducible build and the listing draft (`.ai/docs/amo-listing.md`) are done;
  the maintainer reviews the look and feel and submits to AMO.

- Expired → separate orange state ([ADR-006](../adr/ADR-006-overlay-card-and-status-icons.md)).
- `eddsa-rdfc-2022` → bundle `jsonld` + `rdf-canonize` ([ADR-014](../adr/ADR-014-bundled-jsonld-canonicalisation.md)).
- Ed25519 → minimum Firefox ESR 140, native WebCrypto ([ADR-007](../adr/ADR-007-mv3-desktop-esr.md)).
- Auto-scan → one global switch ([ADR-004](../adr/ADR-004-on-demand-scanning.md)).
